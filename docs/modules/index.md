# Modules

RMF Industrial is split into modules that each run on their own — swap, test, or deploy
any one of them independently. See [Architecture](/guide/architecture) for how they fit
together.

| [Task & Task Orchestrator](./task-orchestrator/) | <https://github.com/ros-industrial/rmf2_task_orchestrator>                                                 |
| [Scheduler](./scheduler)                         | <https://github.com/ros-industrial/rmf2_scheduler>                                                         |
| [UI](./ui)                                       | <https://github.com/ros-industrial/rmf2-ui>                                                                |

For per-module configuration and API documentation, see
